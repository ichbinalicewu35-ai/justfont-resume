# 吳思穎 Alice Wu - justfont 行政營運專員專屬應徵履歷網站

本專案為針對 **justfont（就是字股份有限公司）2026 行政營運專員** 職缺量身打造之個人履歷網站。

## 專案亮點與對齊
1. **帳務與核銷**：年度 10~15 場說明會預算與核銷、雲端記帳範本（節省半天時間、遺失憑證可追溯）。
2. **試算表與資料管理**：XLOOKUP、Word 合併列印寄件標籤、年千份問卷四層自動計算表。
3. **流程、文件與合約**：檔案分層命名規範、備忘與交接清單、公文撰擬與場地租借合約協辦。
4. **AI 與自動化**：Dify 工作流建置、RAG 測試（準確率 90%）、務實評估自動化（不盲目依賴 LLM）。
5. **活動營運與客戶溝通**：連續 5 年主動外撥政策說明、實體講師面對面解惑、個資最小揭露原則。
